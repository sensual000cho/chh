# CHH

Excalidraw + PureRef 스타일 레퍼런스 보드 (Electron 데스크톱 앱).

## 기능
- 항상 위 / 창 투명도 조절, 상단 제목 표시줄, 우클릭 드래그로 창 이동
- **클릭 통과**: 창을 띄운 채 아래 프로그램을 조작합니다. 제목 표시줄 버튼으로 켜고 `Ctrl+Shift+L`로 해제합니다.
- `.chh` 보드 저장·열기, `.excalidraw` 열기, 최근 작업 파일
- 저장되지 않은 변경은 제목에 `•`로 표시하고, 새 보드·열기·닫기 때 저장할지 묻습니다.
- **자동 저장**: 변경 후 잠시 뒤 자동으로 보관합니다. 비정상 종료 후 다시 켜면 저장 안 한 작업과 파일 연결을 복구합니다.
  "저장 안 함"으로 버린 내용도 최근 5개는 자동 저장 백업 폴더에 남습니다 (메인 메뉴 → 자동 저장 백업 폴더 열기).
- 화면 영역 캡처 (기본 `Ctrl+Shift+X`, 메인 메뉴에서 변경 가능)
- **이미지 가져오기**: 제목 표시줄 "이미지" 버튼(여러 장 선택), 파일/웹 이미지 끌어다 놓기, 붙여넣기, 이미지 주소 붙여넣기
- **이미지 자동 정렬**: 선택한 이미지(없으면 전체)를 크기 그대로 빈틈 적게 늘어놓습니다. `Ctrl+Z`로 되돌립니다.
- 이미지 하나를 복사하면 PureRef 등 다른 프로그램에도 이미지로 붙여넣을 수 있습니다.
- **Tab**: 모든 UI 숨기기/보이기 (숨긴 상태에서 창 맨 위에 마우스를 올리면 제목 표시줄이 나타납니다)
- Esc: 메인 메뉴 열기/닫기
- 캔버스 배경색: 고정 6색 + 스펙트럼 직접 선택

### 픽셀판
정해진 크기(최대 512×512)의 픽셀 캔버스입니다. 브러시/지우개/스포이드/채우기/직선/사각형/선택 이동, 좌우·상하 대칭,
레이어(최대 16개), 격자, 되돌리기, 투명 배경 PNG 내보내기(1~32배, 보간 없음)를 지원합니다.
선택한 픽셀판에서 Enter 또는 더블클릭으로 그리기를 시작합니다.

그리기 중 단축키:

| 키 | 동작 |
| --- | --- |
| B / E / I / G | 브러시 / 지우개 / 스포이드(또는 Alt+클릭) / 채우기 |
| L / R / M | 직선 / 사각형(Shift: 속 채우기) / 선택 |
| X / Y | 좌우 대칭 / 상하 대칭 |
| [ ] | 브러시 크기 |
| 스페이스+드래그, 가운데 버튼 드래그 | 화면 이동 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 실행 |
| Delete | 선택 영역 지우기 |
| Ctrl+A | 전체 선택 (선택 도구일 때) |
| Enter | 옮기던 선택 영역 내려놓기 |
| Esc | 선택 해제, 그리기 종료 |

스포이드는 판 밖을 누르면 옆에 놓은 레퍼런스 이미지 등 화면에 보이는 색을 가져옵니다.

## 웹 버전
GitHub Pages 판은 브라우저에 자동 저장되며, 메인 메뉴의 내보내기로 파일에 저장합니다.
제목 표시줄, 화면 캡처, 클릭 통과 등 데스크톱 전용 기능은 없습니다.

## 개발
```bash
npm install
npm run dev          # 브라우저에서 UI 개발 (http://localhost:5173)
npm run electron:dev # Vite dev 서버를 띄운 상태에서 Electron 창으로 실행
npm run build && npm run electron   # 빌드 결과(dist/)로 Electron 실행
npm test             # 단위 테스트
npm run test:e2e     # 실제 앱을 임시 폴더로 띄워 저장·복원·종료 등을 확인 (창이 떴다 사라지고 클립보드를 덮어씁니다)
npm run lint
```

## 구조
- `electron/` — 메인 프로세스, preload(`window.chh` API), 화면 캡처 창
- `src/` — React UI (Excalidraw)
- `src/boardStore.js` — 자동 저장소 (데스크톱: 파일, 웹: IndexedDB)
- `src/pixel/` — 픽셀판
- `tests/` — 단위 테스트, 앱 시나리오 테스트

## 참고
- 캔버스는 Excalidraw **라이트 테마(색 반전 필터 없음)** 로 그리고, UI 에만 다크 팔레트를 입힙니다.
  (다크 테마를 쓰면 이미지·배경 색이 원본과 달라집니다.) 다크 UI 규칙은 `npm run gen:dark-css` 로
  `src/excalidraw-dark.css` 를 자동 생성합니다. @excalidraw/excalidraw 버전을 올리면 다시 실행하세요.
- `npm run dist` → `release/` 에 포터블(`CHH.exe`)과 설치판(`CHH-Setup.exe`)을 만들고 프로젝트 루트의 `CHH.exe`,
  `CHH-Setup.exe`, `CHH-공유용.zip` 을 덮어씁니다. `.chh` 더블클릭 연결은 설치판에서만 등록됩니다.
- `CHH_` 로 시작하는 개발용 환경 변수는 패키징되지 않은 실행에서만 동작합니다.
