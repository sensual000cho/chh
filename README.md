# Thinking Chair (생각의자)

레퍼런스와 메모를 모아 놓고 생각을 넓히는 브레인스토밍 보드 (Excalidraw + PureRef 스타일, Electron 데스크톱 앱).
예전 이름은 CHH 입니다. 보드 파일 확장자 `.chh` 는 그대로 씁니다.

## 기능
- 항상 위 / 창 투명도 조절, 상단 제목 표시줄, 우클릭 드래그로 창 이동
- **클릭 통과**: 창을 띄운 채 아래 프로그램을 조작합니다. 제목 표시줄 버튼으로 켜고 `Ctrl+Shift+L`로 해제합니다.
- `.chh` 보드 저장·열기, `.excalidraw` 열기, 최근 작업 파일
- 저장되지 않은 변경은 제목에 `•`로 표시하고, 새 보드·열기·닫기 때 저장할지 묻습니다.
- **자동 저장**: 변경 후 잠시 뒤 자동으로 보관합니다. 비정상 종료 후 다시 켜면 저장 안 한 작업과 파일 연결을 복구합니다.
  "저장 안 함"으로 버린 내용도 최근 5개는 자동 저장 백업 폴더에 남습니다 (메인 메뉴 → 자동 저장 백업 폴더 열기).
- 화면 영역 캡처 (기본 `Ctrl+Shift+X`, 메인 메뉴에서 변경 가능, `Esc`로 취소)
- **이미지 가져오기**: 제목 표시줄 "이미지" 버튼(여러 장 선택), 파일/웹 이미지 끌어다 놓기, 붙여넣기, 이미지 주소 붙여넣기
- **GIF**: 움직이는 GIF·WebP·PNG가 보드에서 움직입니다. 화면 밖이거나 아주 작게 보일 때는 멈춥니다.
- **영상**: mp4, webm 등 영상 파일을 이미지처럼 넣고, 재생 버튼을 눌러 재생합니다(음소거로 시작, 반복 재생). 마우스를 올리면 일시 정지·이동·소리 조절 막대가 나옵니다.
  20MB 이하는 보드 파일에 함께 저장되고, 더 큰 영상은 원본 파일 위치에 연결됩니다(원본을 옮기면 재생되지 않습니다).
- **영상 주소**: 유튜브·비메오 주소를 붙여넣거나 끌어다 놓으면 재생 카드가 됩니다(가운데를 누르면 재생). `.mp4`처럼 영상 파일을 가리키는 주소도 재생됩니다. 주소를 글자로 붙여넣으려면 `Ctrl+Shift+V`.
- **메모**: `N`을 누르면 마우스 위치에 포스트잇을 만들고 바로 쓸 수 있습니다. 아무것도 안 쓰면 사라집니다.
- **묶음**: 항목을 선택하고 `Alt+G`를 누르면 이름 붙은 영역으로 묶입니다. 묶음을 끌면 안의 항목이 함께 움직입니다.
  이름은 묶음을 선택하고 Enter로 바꿉니다.
- **보드에서 찾기**: `Ctrl+F`로 메모와 글자를 찾습니다.
- **출처 보관**: 웹에서 가져온 이미지에 원본 주소가 링크로 남습니다.
- **이미지 자동 정렬**: 선택한 이미지나 묶음(선택이 없으면 묶음 밖 전체)을 크기 그대로 빈틈 적게 늘어놓습니다. `Ctrl+Z`로 되돌립니다.
- 이미지 하나를 복사하면 PureRef 등 다른 프로그램에도 이미지로 붙여넣을 수 있습니다.
- **Tab**: 모든 UI 숨기기/보이기 (숨긴 상태에서 창 맨 위에 마우스를 올리면 제목 표시줄이 나타납니다)
- Esc: 메인 메뉴 열기/닫기
- **도움말**: `F1`, `?`, 오른쪽 아래 ? 버튼, 메인 메뉴 → 도움말에서 이 앱의 기능과 단축키를 봅니다. 그리기 도구 단축키는 도움말 아래 "그리기 도구 단축키 보기" 버튼으로 봅니다.
- 캔버스 배경색: 고정 6색 + 스펙트럼 직접 선택
- 선 색상·배경색: 속성 패널의 색 버튼을 누르면 스펙트럼 선택기가 열립니다. `Ctrl+Z` 한 번이면 바꾸기 전 색으로 돌아갑니다.
- 시작하면 마지막에 열었던 보드와 창 위치·크기를 되살립니다. `.chh` 파일은 창에 끌어다 놓아도 열립니다.

## 웹 버전
GitHub Pages 판은 브라우저에 자동 저장되며, 메인 메뉴의 내보내기로 파일에 저장합니다.
제목 표시줄, 화면 캡처, 클릭 통과 등 데스크톱 전용 기능은 없습니다.

## 개발
```bash
npm install
npm run dev          # 브라우저에서 UI 개발 (http://localhost:5173)
npm run electron:dev # Vite dev 서버를 띄운 상태에서 Electron 창으로 실행
npm run build && npm run electron   # 빌드 결과(dist/)로 Electron 실행
npm test             # 단위 테스트
npm run test:e2e     # 실제 앱을 화면 밖에 띄워 저장·복원·종료 등을 확인 (포커스·클립보드를 건드리지 않음)
npm run lint
```

`E2E_NET=1`을 주면 실제 유튜브 접속까지 확인합니다.
화면 캡처·클립보드·창 복원까지 점검하려면 `E2E_FULL=1`을 주고 `node tests/e2e.mjs`를 실행합니다. 실제 화면과 클립보드를 쓰므로 다른 작업 중에는 쓰지 마세요.

## 구조
- `electron/` — 메인 프로세스, preload(`window.chh` API), 화면 캡처 창
- `src/` — React UI (Excalidraw)
- `src/boardStore.js` — 자동 저장소 (데스크톱: 파일, 웹: IndexedDB)
- `src/MediaLayer.jsx` — 움직이는 GIF·영상을 캔버스 위에 얹어 재생. 영상은 이미지 요소의 `customData.video` 에 저장 (`src/videos.js`)
- `tests/` — 단위 테스트, 앱 시나리오 테스트

## 참고
- 캔버스는 Excalidraw **라이트 테마(색 반전 필터 없음)** 로 그리고, UI 에만 다크 팔레트를 입힙니다.
  (다크 테마를 쓰면 이미지·배경 색이 원본과 달라집니다.) 다크 UI 규칙은 `npm run gen:dark-css` 로
  `src/excalidraw-dark.css` 를 자동 생성합니다. @excalidraw/excalidraw 버전을 올리면 다시 실행하세요.
- `vite.config.js` 는 빌드할 때 Excalidraw 코드 일부(배율 범위, 움직이는 요소 건너뛰기)를 바꿉니다. 버전을 올려 코드 모양이 달라지면 빌드가 멈추고 알려 줍니다.
- 유튜브는 Referer 없이 열면 오류 153 으로 막히므로 `electron/main.cjs` 의 `setupEmbeds` 가 앱 ID 를 붙여 보냅니다.
- `npm run dist` → `release/` 에 포터블(`ThinkingChair.exe`)과 설치판(`ThinkingChair-Setup.exe`)을 만들고 프로젝트 루트의
  `ThinkingChair.exe`, `ThinkingChair-Setup.exe`, `ThinkingChair-공유용.zip` 을 덮어씁니다. `.chh` 더블클릭 연결은 설치판에서만 등록됩니다.
- `CHH_` 로 시작하는 개발용 환경 변수는 패키징되지 않은 실행에서만 동작합니다.
- 처음 실행할 때 예전 이름(CHH)의 설정 폴더(`%APPDATA%\CHH`)에서 설정·자동 저장·최근 파일을 새 폴더로 복사해 옵니다.
